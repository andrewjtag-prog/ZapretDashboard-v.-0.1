# Zapret Dashboard 🛡️

Удобная графическая оболочка (GUI) для обхода блокировок с помощью утилиты [zapret](https://github.com/bol-van/zapret). 

Вместо того чтобы каждый раз искать нужный `.bat` файл в папках, запускать его от имени администратора и смотреть в черное окно консоли, вы можете управлять всем через простой и стильный интерфейс.

## 🌟 Возможности

- **Выбор стратегии (ALT) в один клик.** Все батники автоматически подтягиваются из встроенной папки. Вам не нужно ничего искать.
- **Автоматическое переключение.** При запуске новой стратегии предыдущая корректно останавливается. Никаких конфликтов `winws.exe`.
- **Управление списком сервисов.** Добавляйте свои домены (например, `rutracker.org`), и они будут автоматически записываться в `list-general-user.txt`. Перезапуск не требуется — zapret подхватит изменения на лету.
- **Автозапуск с Windows.** Программа автоматически поднимает последнюю активную стратегию при включении компьютера. Интернет будет работать сразу после загрузки.
- **Темная тема.** Стильный терминальный интерфейс, который не бьет по глазам.
- **Встроенный Zapret.** Все файлы утилиты (батники, `winws.exe`, списки) уже вшиты в программу. При первом запуске они автоматически распакуются в безопасную папку `%LocalAppData%`.

## 🚀 Как запустить

1. Перейдите в раздел **Releases** (Релизы) на странице этого репозитория.
2. Скачайте последний архив `ZapretDashboard.zip`.
3. Распакуйте архив в любую удобную папку (например, на Рабочий стол).
4. Запустите `ZapretDashboard.exe`.
5. Выберите нужный ALT в списке и нажмите **Connect**. Разрешите запрос от имени администратора (UAC).

*Важно: Приложение не требует установки. Вы можете удалить папку в любой момент.*

## ⚠️ Требования

- Windows 10 / 11 (64-bit).
- Права администратора (необходимы для работы драйвера `WinDivert`).

## 🛠️ Сборка из исходников

Если вы хотите собрать проект самостоятельно, вам понадобится **Visual Studio 2022** с установленной нагрузкой «Разработка классических приложений .NET».

1. Клонируйте репозиторий.
2. Откройте файл `ZapretDashboard.sln`.
3. Выберите конфигурацию **Release**.
4. Нажмите **Сборка** -> **Собрать решение**.
